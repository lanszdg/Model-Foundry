# v0.5 执行基准与验收

本轮修复可验证的执行偏差。工程对象仍为 Atlas 70B Dense、80 层、32 × H100、BF16；原有建设、集群、数据、训练和发布路径保留。此基准不把内部检查通过等同于全部真实软件复刻完成。

## 固定协议

| 对象 | 协议 | 约束 |
| --- | --- | --- |
| 采样 | `decode-v2` | 完整输入用于构建请求前缀；当前条件 Token 模型仍仅使用最后两个 Token 作为概率上下文 |
| 评测 | `evaluation-v2` | Unicode 逐字符多重集 F1、固定任务/种子、验证 NLL、发布门槛；保存所用协议 |
| 新训练 | `adam-v2` | 配方学习率乘预热/余弦调度，无按训练阶段设置的隐藏倍率 |
| 旧训练 | 历史优化器语义 | 老检查点续训保留原语义，避免恢复后悄悄切换更新尺度 |

## 操作契约

1. **入队不生成答案。** 请求只有输入、采样配置、随机数状态和空的输出；没有预生成的未来 Token。
2. **Prefill 不抽样。** 处理输入与重计算消耗调度预算，采样随机数保持不变。
3. **Decode 逐步执行。** 每次获得解码预算才读取当前条件概率、执行 greedy 或 temperature/top-p、采样并更新上下文。评测与服务使用同一个解码器，不再从训练语料检索答案开头。
4. **暂停释放 KV。** 显式暂停后不继续抽样；恢复重新排队，重建 KV 后从原 RNG 和解码位置继续。客户端 deadline 仍继续计时，暂停不能规避超时。
5. **抢占不改变采样。** KV 抢占释放物理租约，保留逻辑输出与 RNG，重计算不重复消耗随机数。
6. **取消和超时停止执行。** 排队时取消或超时不会产生 Token；运行中结束后停止抽样并释放 KV。
7. **停止串不泄漏。** 暂存可能匹配停止串的文本后缀，完整命中后不显示停止串。用量保留实际采样的 Token 数，文本与 Token 计数分别记录。
8. **状态可保存。** JSON 工程保存已生成 Token、上下文、RNG、采样次数、停止状态和事件；恢复的结果与不中断运行保持一致。
9. **评测有版本。** 旧报告保留并标记过期，不能直接用于新转换或冷加载；已驻留的旧模型继续服务。对同一检查点重新评测后更新注册记录。
10. **框架接口不伪造成功。** 当前模型带 `labels` 时返回逐 Token loss，不返回完整词表 logits；对这个结果再调用尚未实现的 `torch.nn.functional.cross_entropy` 会报告带源码位置的 `NotImplementedError`。

## 独立数值与状态检查

F1 的字符交集按出现次数取较小值。公式为 `2 × matched / (prediction_length + reference_length)`。`aaaaaa` 对 `a` 应为 `2/7`，`aab` 对 `ab` 为 `0.8`，`😀😀` 对 `😀` 为 `2/3`；任何输入的值都在 `[0, 1]` 内。

```bash
node verify.mjs
```

`verify-v5.cjs` 使用受控 logits 验证真实采样与调度接口，不注入未来输出。覆盖入队/Prefill 零采样、逐步 RNG、暂停/重载/恢复等价、停止串跨 Token、temperature=0、EOS、字节回退、取消、deadline、报告迁移及学习率数值。既有 KV 压力检查也改为经采样器逐步生成，不再注入 `plan` 数组。

浏览器验收使用正常导入与按钮操作，核对暂停、恢复、取消、解码 Trace、评测协议和工程刷新恢复。

## 当前边界

模型行为仍是条件 Token 分布，尚未实现 Transformer 注意力与完整上下文学习。70B 的显存、训练和服务耗时仍来自工程资源模型；每 GPU 进程的完整 micro batch 计算/通信调度、硬件实测标定与全部 Linux/Python/CUDA 兼容不在本轮验收范围。逐步 Decode 是执行机制改进，不能据此宣称性能或语言能力与真实 70B 一致。
