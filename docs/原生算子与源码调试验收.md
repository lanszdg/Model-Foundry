# v0.10 · 原生架构算子与源码调试验收

本版推进两条模型架构的计算与源码开发操作。仍是纯 HTML、本地运行、零外部运行依赖。这里记录可执行范围与证据，不把内部检查数当作真实软件的复刻比例。

## 计算中新增的内容

| 路线 | 实际执行的运算 | 可检查的结果 |
| :--- | :--- | :--- |
| GLM-5.3 | Q 的低秩投影；KV 压缩与展开；独立索引器对因果历史做 top-k 选择；sigmoid 门控、校正偏置选择专家、归一化权重 × 2.5、共享专家 | 压缩形状、逐 Token 索引、专家选择、实际参数梯度 |
| Qwen3.8 | 三个循环 Gated DeltaNet block 后接一个门控注意力 block；深度因果卷积、QK 归一化、学习 decay/beta、循环矩阵更新；零中心 RMSNorm、QK head norm、部分三轴旋转位置 | 逐层 state、decay/beta、KV、实际 logits 与命名梯度 |
| Qwen 视觉路径 | RGB → 8×8 归一化 → 两帧 tubelet → 16 Patch → 单层双向 ViT → 2×2 merger → 四个视觉前缀 | 图像变化影响语言 logits；caption loss 反传到 Patch/ViT/merger |

默认新工程为 4 层、hidden 16、FFN 32、2 个头、64 Token 上下文；GLM 默认 4 个路由专家、top-2、前三层 dense。它是预算内执行结构，不是官方完整模型的层数、参数或效果。GLM 的独立索引选择目前冻结，符合所核查推理实现的无梯度选择；未实现其索引器训练损失。

每个工程生成可编辑的 `architecture.json`。修改结构会改变真实分配的张量，继续 SFT/DPO 时结构不一致会失败。GLM 经过继续预训练、SFT、DPO、评测、导出、部署；Qwen 经过视觉对齐、多模态 SFT、评测、导出、部署。权重、优化器、数据/源码摘要和模型资产沿已有工程状态保存。旧模型存档保留旧结构，不自动转换不兼容权重。

原生计算图页读取实际层快照和命名梯度。实验对比按真实参数计算变化数量和 L2 距离，展示训练 loss、验证 loss、数据与源码摘要，可导出 CSV。不同结构之间不计算参数距离。

## 源码开发操作

Code 工作区包含文件树、跨文件文本搜索与跳转、文件页签、保存、语法/配置检查、Python 运行、行断点、继续、F10 越过、F11 进入函数、变量和只读 Watch。它使用项目现有 Python AST 解释器，按真正执行的语句暂停，不按预设行号播放动画。

调试启动时冻结源码和可读文件，继续运行时不会悄悄改用编辑后的版本；重新启动才应用改动。会话与变量、输出可随工程保存。重放仅支持受控纯计算、JSON、只读 pathlib 和项目 Python 模块；不支持的第三方导入会明确失败。Watch 禁止函数调用，错误保留文件、行号和异常种类。

快速验收：Code → 调试示例 → 第 10 行点断点 → F5 启动 → F5 继续。此时 `global_batch=8`、`micro_batch=2`、`accumulation=4`，Watch `global_batch / micro_batch` 为 4。继续后输出 `total_tokens 1024`。调整配置后重新启动，变量和断言会随输入变化。

## 数值与工作流证据

`node verify.mjs`：新增 404 项，连同既有检查共 1,521 项。新增覆盖每类可训练张量的有限差分、冻结索引器、MoE 路由、因果选择、整段/增量一致、TP/PP 数值一致、视觉梯度、safetensors 精确往返、两条完整工程链、断点/Watch/函数单步、异常与会话保存，以及输入结构拒绝。

`python verify-native-reference.py` 使用独立 NumPy 运算和相同状态字典，未调用 JavaScript 内核。完整前向最大绝对误差：GLM `1.33e-15`、Qwen `3.78e-15`；独立 Delta 循环状态与输出一致。这验证所声明预算结构的数学计算，不代表官方完整模型一致性或 GPU 性能校准。

浏览器另验收：导入原生工程，读取三个 Delta 状态与注意力层、视觉张量及梯度；选择两个训练运行得到 21,908 个变化参数、L2 距离约 0.035694；重新提交 Qwen SFT 得到实测 loss 5.72690；执行源码搜索、断点、Watch 与 F10。浏览器训练值仅对应随包样例的一步训练，不是模型质量基准。
