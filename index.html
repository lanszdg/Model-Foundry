FIELD MANUAL / 01
工程手册
你接手了 Atlas 70B 项目。机房设备已到位，平台需要由你建立。
现场操作
WASD 移动，按住鼠标拖动观察。靠近设备按 E，或点击设备标记。靠近工位后按 Tab 坐下，Esc 离座。机柜操作需要靠近设备。
建设顺序
开柜接线 → 上电 → 装机 → 配网 → GPU 运行时 → 存储 → 调度 → 数据与实验平台 → 语料 → 训练 → 后训练 → 评测 → 推理。
工程时间
右上角切换 1× / 4× / 12×。关闭页面后工程时间冻结，返回时从存档继续。导出存档可以保存多个工程分支。
第一组命令
# 先在机柜接好电源、管理网和 IB
labctl status
labctl power --all
labctl provision
labctl network apply
labctl runtime install
labctl install storage
systemctl start storage
mount storage-01:/data /data
故障恢复
训练中断后，先修复节点、网络或存储，再从完整检查点恢复。显存不足要修改训练配方；过高学习率可能导致训练发散。
当前版本支持逐节点认证与注册、GPU 分配、分片检查点与恢复，以及 70B Dense 的预训练、SFT、DPO 与服务交付。工程配置、日志、指标、文件和产物共享同一份世界状态。
